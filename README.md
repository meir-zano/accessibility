
# Accessibility Widget ♿ - Documentation (v2.0)

ספריית JavaScript פרימיום, קלה ומתקדמת להוספת תפריט נגישות מלא לאתרים. הכלי נבנה בגישת Zero Dependencies (ללא ספריות חיצוניות), שומר על מהירות האתר ומספק חוויית משתמש עשירה ומקצועית העומדת בתקני הנגישות המחמירים ביותר (WCAG AAA).

## 🚀 הטמעה מהירה

הוסף את השורה הבאה לפני סגירת תגית ה-`</body>` באתר שלך:



```html
<script src="https://cdn.jsdelivr.net/gh/meir-zano/accessibility@latest/main.min.js"></script>

```

## ⚙️ התאמה אישית (Configuration)

ניתן לשלוט במראה, בתפקוד ובמיקום של הווידג'ט על ידי הגדרת האובייקט `mzAccessibilityConfig` **לפני** טעינת הסקריפט:

```html
<script>
  window.mzAccessibilityConfig = {
    theme: 'modern',         // עיצוב המניו
    menuLayout: 'grid',      // סידור כפתורים: 'grid' או 'list'
    position: 'bottom-right',// מיקום האייקון: 'bottom-right', 'bottom-left', 'top-right', 'top-left', 'mid-right', 'mid-left'
    primaryColor: '#0D6EFD', // צבע המותג שלך (צבע ראשי של התפריט)
    defaultLang: 'he',       // שפת ברירת מחדל: 'he' או 'en'
    maxTextZoomPercent: 400, // מקסימום הגדלת טקסט (מומלץ 400% לתקן מחמיר)
    minTextZoomPercent: 50,  // מינימום הקטנת טקסט
    iconType: 'person',      // סוג אייקון מרחף: 'wheelchair', 'human', 'eye', 'person'
    iconStyle: 'default',    // סגנון אייקון: 'default', 'outline', 'square', 'glow', 'tab'
    pro: false               // תמיכה ב-CSS פנימי של האתר להגדלה מקצועית
  };
</script>

```

### 🎨 סגנונות עיצוב (Themes)

הווידג'ט מגיע עם מגוון רחב של עיצובים מוכנים מראש:

* `modern`: עיצוב צף קלאסי ונקי.
* `glass`: מראה זכוכית שקוף (Glassmorphism) עם טשטוש רקע.
* `neumorphism`: עיצוב תלת-ממדי רך ואלגנטי.
* `material`: סגנון Google Material עם צלליות עמוקות.
* `dark`: מצב כהה מובנה.
* `high-contrast`: ניגודיות מקסימלית בשחור וצהוב (ללקויי ראייה).
* `rounded`: פינות מעוגלות מאוד למראה ידידותי.
* `cyberpunk`: עיצוב ניאון עתידני.
* `retro`: מראה קלאסי בסגנון Windows 95.
* `minimal`: עיצוב ברוטליסטי נקי בקווי מתאר.
* `sidebar`: סרגל צד הנפרס על פני כל גובה המסך.
* `compact`: גרסה מצומצמת לחיסכון במקום.

## ✨ תכונות עיקריות

התפריט מחולק לקבוצות לוגיות לנוחות המשתמש:

### 📝 התאמות טקסט וקריאה

* **שליטה מדויקת (Sliders):** סליידרים להגדלת טקסט (עד 400%), ריווח אותיות וריווח שורות.
* **יישור טקסט:** כפתורים ליישור גורף של כל הטקסט באתר לימין, לשמאל או למרכז.
* **גופנים נגישים:** החלפה ל"גופן קריא" (Sans-Serif) או פונט ייעודי לדיסלקציה.
* **הדגשות:** הדגשת כותרות (H1-H6) והדגשת קישורים בקו ובצבע בולט.

### 🎨 התאמות צבע ותצוגה

* **בורר צבעים אישי:** המשתמש יכול לבחור צבע רקע וצבע טקסט מותאמים אישית לכל האתר.
* **פריסטים פופולריים:** 5 שילובי צבעים מוכנים מראש (שחור-לבן, צהוב-שחור, כחול-לבן וכו').
* **אפקטים ויזואליים:** ניגודיות רכה, מצב אפור (Grayscale), היפוך צבעים, ושינוי רוויה (Saturation) גבוהה/נמוכה.
* **ניקוי מדיה:** הסרת מדיה (הסתרת תמונות/סרטונים) ועצירת אנימציות (הקפאת אנימציות במקום).

### 🔍 ניווט ומיקוד

* **מיקוד קריאה (Reading Mask):** פס אור העוקב אחר העכבר ומחשיך את שאר המסך (פתרון מעולה ל-ADHD).
* **זכוכית מגדלת:** הגדלה אזורית במיקום הסמן.
* **סמן עכבר:** אפשרות להגדלת סמן העכבר לסמן בולט במיוחד.
* **ניווט מקלדת:** הדגשת אלמנטים בפוקוס בעת שימוש ב-TAB.
* **הקראה קולית:** מנוע Speech Synthesis המקריא טקסטים במעבר עכבר.
* **תיאורי תמונות:** חשיפה דינמית של טקסט חלופי (ALT) מתחת לתמונות.
* **השתקת צלילים:** השתקה מיידית של כל קבצי האודיו והוידאו באתר.

## 🛡️ "אל תיגע לי בעיצוב" (mz-ignore)

כדי למנוע מהסקריפט להגדיל או לשנות אלמנטים גרפיים רגישים (כמו לוגו או אייקונים עיצוביים), פשוט הוסף להם את הקלאס: `class="mz-ignore"`. הסקריפט יתעלם מכל אלמנט הנושא קלאס זה.

## 🛠 טכנולוגיות וביצועים

* **Vanilla JavaScript:** קוד נקי ומהיר ללא תלויות חיצוניות.
* **Dynamic ARIA:** עדכון מאפייני `aria-pressed` בזמן אמת לנגישות מלאה לקוראי מסך.
* **Jitter-Free Scaling:** מנגנון חכם המונע קפיצות ורעידות של התפריט בעת שינוי גדלים.
* **Responsive Design:** התפריט מתאים את עצמו לכל גודל מסך ולכל רמת זום מבלי להישבר.
* **LocalStorage:** שמירה אוטומטית של הגדרות המשתמש לביקור הבא.
